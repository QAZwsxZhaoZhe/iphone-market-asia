# AI 能力与后续发展

## 定位

AI 不是单独做一个聊天功能，而是为二手 iPhone 业务提供四类可衡量能力：

- 价格判断：估算合理收购价和转售价，给出置信区间。
- 机会判断：比较要价与同款市场区间，排序潜在利润和风险。
- 质量控制：识别重复、错误价格、故障机、配件和虚假商品。
- 经营辅助：自动生成日报、异常提醒和数据问答。

## 当前已落地

- 同款同容量可比估值
- 基于中位数绝对偏差的异常价格过滤
- 合理价格区间、建议收购上限和建议转售参考
- 高、中、低置信度及样本量
- 潜在机会评分和风险标记
- CLI 和本地 HTTP API
- 实际收购、转售、费用和维修成本反馈记录
- 估值绝对误差、MAPE、区间覆盖率、真实利润和 ROI 评估

当前算法版本是 `comparable_median_v1`。它适合样本量有限、还没有真实成交价的
冷启动阶段，不代表最终模型。

## 分工边界

AI 负责人负责：

- 数据质量、字段需求、标注规范和反馈闭环
- 估值、排序、异常识别和经营助手能力
- 评估集、准确率、置信度、漂移和版本管理
- AI 产品需求、验收标准和业务指标

后端工程师负责：

- 数据库、接口、权限、任务队列和部署
- AI 服务的调用、缓存、重试、限流和监控
- 前端需要的稳定数据契约

## 90 天计划

### 第 1 个月

- 补充成色、电池健康、维修史、保修、运费和卖家信用字段
- 记录实际收购价、转售价和成交结果
- 为每个机型容量的估值建立人工验收集
- 将现有可比估值接入真实工作流并收集反馈

当前已完成第一步中的基础反馈闭环：竞品列表页暂时拿不到的字段不伪造，
业务侧可在每次决策和成交后写入真实数据，积累到 30 条有效成交样本后再用于模型回测。

### 第 2 个月

- 训练梯度提升树或线性基线，与 `comparable_median_v1` 做回测
- 加入发布时间、市场景气度、汇率和平台来源特征
- 对低置信度样本转人工复核
- 上线异常低价、重复商品和价格突变提醒

### 第 3 个月

- 试点图片成色识别、电池健康 OCR 和故障风险识别
- 建立跨市场利润评分，纳入汇率、物流、税费和流动性
- 上线只读取授权数据的经营问答助手
- 建立模型监控、漂移告警和回滚流程

## 评估指标

- 估值平均绝对误差和中位数绝对百分比误差
- 合理区间覆盖率
- 异常列表准确率和召回率
- 人工复核一致率
- 机会建议的采纳率和真实利润
- 单次推理成本、响应时间和失败率

## 不先做的事情

- 不先微调大语言模型
- 不先做通用聊天机器人
- 不先上复杂向量数据库
- 不在缺少真实成交数据时承诺高精度定价
- 不用爬虫绕过验证码或获取未授权数据
